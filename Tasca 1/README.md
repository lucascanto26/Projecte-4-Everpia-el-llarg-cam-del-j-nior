# Tasca 1: Gestió projecte amb metodologia Kanban

__Presentació de l'activitat__

Com a consultors júnior, heu de ser capaços de gestionar un projecte amb metodologia Kanban, per poder planificar, organitzar i controlar les tasques del projecte de manera eficient.

No només es tracta de moure tasques entre columnes, cal que feu una assignació de les tasques entre els membres de l'equip, que feu una estimació del temps que trigareu a realitzar-les i que feu un seguiment de l'estat de les tasques al llarg del projecte, indicant les dates de venciment, de manera que es pugui tenir un control del temps real i observar desviacions respecte a la planificació inicial.
