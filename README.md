## Instruccions

1. Afegiu com a col·laboradors del vostre repositori a GitHub els professors amb tasques de revisió i avaluació. Això permetrà que puguin accedir al vostre repositori i revisar el vostre treball.

   - [Professors col·laboradors SMX 2n A](docs/profes2A.md)
   - [Professors col·laboradors SMX 2n B](docs/profes2B.md)

2. **Organització del repositori:**
   - Cada activitat ha d'estar dins d'una carpeta titulada `Tasca01`, `Tasca02`, etc.
   - Dins de cada carpeta de tasca, heu d'incloure un arxiu `README.md` amb la descripció detallada de l'activitat realitzada.

3. **Procediment de treball:**
   - A mesura que completeu cada tasca, actualitzeu el vostre repositori local amb els canvis.
   - Cada dia, abans de finalitzar la jornada, pugeu els canvis al  repositori remot a GitHub.
   - No us oblideu de fer el seguiment de les tasques al Kanban del projecte, actualitzant l'estat de cada tasca a mesura que avanceu.

## Estructura del projecte

```text

projecte4/

├── Tasca02/

```

**Recordeu**: poseu a dins de cada carpeta de tasca un arxiu `README.md` amb la descripció detallada de l'activitat realitzada, les imatges a dins una carpeta `img` o el nom que indiqui l'enunciat en cada casa. Eviteu penjar arxius molt grans, com vídeos, millor utilitzar enllaços al núvol (Google Drive, OneDrive, etc.) si cal.

> GitHub limita la mida del repositori (carpeta `.git`) a més, arxius grans ralentitzen les operacions de sincronització i poden provocar errors.
